# Proposal: 00981A 成分股動能 K 線圖

## 概述

目前 00981A 投資監控僅能顯示靜態的持股比例與最新收盤價。為了提升投資決策品質，本計畫旨在整合 Finlab 的歷史價量數據，在 Web 介面上提供互動式的動態 K 線圖（包含開高低收與成交量）。

## 目標

- 使用者點選持股清單中的任何一檔個股，即可彈出該個股的動能 K 線圖。
- 圖表支援動態縮放、拖曳，並顯示成交量。
- 數據來源完全自動化，透過每日的 ETF Tracker 任務同步到 Supabase。

## 範疇

- **資料庫層**：新增 `stock_prices_daily` 表，用於儲存 OHLCV 數據。
- **後端流水線**：擴充 Python 腳本，每日抓取並更新 00981A 成分股的 250 日歷史資料。
- **後端 API**：建立 Next.js API Route，提供前端查詢個股歷史價微服務。
- **前端組件**：整合 `lightweight-charts`，實作點選列後顯示 Modal 圖表。

## 效益

- 直觀觀察成分股的技術面走勢。
- 輔助判斷 ETF 調倉背後的動能邏輯。
- 提升系統的專業感與使用體驗。
