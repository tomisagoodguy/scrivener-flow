# Proposal: 任務完成過濾功能 (Task Completion Filter)

## Problem

現有的房地產交易 Kanban 看板中，所有任務（無論已完成或未完成）都同時顯示。
隨著流程推進，已完成的項目持續佔據畫面空間，造成視覺干擾，使用者難以快速辨識「還有哪些事情要做」。

同事提出需求：**「確認按完的消失鈕」**——已完成的任務應該能從畫面上隱藏，讓使用者聚焦於待辦事項。

## Solution

在 Kanban 看板加入「顯示模式切換」功能：

1. **新增 Toggle 開關**（位於板頭區域）：在「全部」與「僅未完成」之間切換
2. **完成動畫**：任務勾選後，卡片執行淡出 + 向上滑動動畫，再從 DOM 中移除（或隱藏）
3. **持久化偏好**：使用者的顯示模式偏好存入 `localStorage`，重整頁面後保留

## Capabilities

### New Capabilities

- `task-visibility-toggle`: 全局 Toggle，讓使用者切換「顯示全部任務」/「僅顯示未完成任務」
- `task-completion-animation`: 任務卡片勾選完成時的淡出滑動動畫
- `display-mode-persistence`: 將顯示模式偏好存入 localStorage 並在頁面載入時還原

### Modified Capabilities

- `task-card-render`: 現有的任務卡片需支援「隱藏已完成」的 filter 邏輯，並整合動畫狀態

## Impact

- **影響元件**：`KanbanColumn`、`TaskCard`（或相關任務展示 component）
- **影響 State**：新增 `showCompleted: boolean` 全局或 column-level 狀態
- **依賴**：無新增外部依賴（純 CSS animation + React state）
- **無 API 變動**：純前端功能

## 流程階段與任務清單（依使用者提供的資料）

### 一、簽約階段

- 確認通訊方式
- 掃描文件
- 送各項申請

### 二、用印階段

- 通知買方匯入用印款及預收規費
- 確認用印款及預收規費有無匯入
- 列印過戶及水電文件
- 確認用印款達成條件是否達成
- 約用印
- 買方用印
- 賣方用印

### 三、貸款階段

- 貸款預估
- 請銀行約客戶寫貸款申請書
- 確認貸款核准條件
- 領設定文件
- 預計過戶完成日確認代償金額
- 通知銀行代償資料
- 過戶完成通知撥款
- 送他項權利登記
- 追前手清償證明
- 塗銷文件準備
- 地政送塗銷
- 送塗後謄本 / 過戶後謄本
- 二撥進履保

### 四、完稅階段

- 通知買方匯入完稅款
- 確認完稅款有無匯入
- 報稅（最後繳納日）：確認登記人後報稅
- 整卷
- 出款繳稅
- 送地政過戶
- 領件（領取權狀及新謄本）

### 五、交屋階段

- 交屋整理
- 水電瓦斯過戶
- 辦理交屋
- 房地合一申報（30日內）
- 結案

## Success Criteria

1. Toggle 開關可正常切換兩種顯示模式
2. 「僅未完成」模式下，已完成任務不顯示（含動畫過渡）
3. 「全部」模式下，已完成任務顯示為灰色/劃線狀態
4. 切換模式偏好在 `localStorage` 中正確保存與還原
5. 動畫流暢，不影響其他任務的排版跳動
6. 每個 Kanban 欄位的計數（已完成/總計）即時更新
