## 1. 元件擴充：收合能力

- [x] 1.1 依 design「以 props 擴充既有元件，不另建收合外殼元件」與「收合時仍執行資料載入（不做懶載入）」為 `EisenhowerMatrix.tsx` 新增選用 props `collapsible?: boolean`（預設 `false`）、`defaultCollapsed?: boolean`（預設 `false`）：`collapsible=true` 時標題列右側加收合/展開按鈕（chevron icon），矩陣本體（待分類橫列 + 象限格）依本地 state 決定是否渲染，初始值取 `defaultCollapsed`；`useEisenhowerMatrix()` 無論收合與否都在掛載時照常執行（不做懶載入，收合只影響渲染不影響資料抓取）；`collapsible=false`（含省略）時完全不顯示收合按鈕、本體一律可見（首頁 `<EisenhowerMatrix />` 呼叫端不變）。完成行為：滿足 spec Requirement「Homepage renders an Eisenhower matrix aggregating party names from active cases」中「always expanded with no collapse control」（首頁）與「collapsible section that starts collapsed」（/cases）兩種行為。驗證：新增/更新 Jest 測試涵蓋 (a) 不傳 props 時本體可見且無收合按鈕、(b) `collapsible defaultCollapsed` 時初始只見標題列、點擊展開後本體出現、(c) 收合狀態下 hook 仍已完成資料載入（展開當下無額外 loading 延遲），`yarn test --testPathPatterns eisenhower` 綠燈。
