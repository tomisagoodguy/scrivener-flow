# 富文本編輯器功能測試清單

## 測試環境
- 頁面: http://localhost:3000/notes
- 編輯器: RichTextEditor 組件

## 測試項目 (18 個功能)

### 1️⃣ 文字格式化 (5 個)
- [ ] **粗體** - 選取文字 → 點擊 Bold 按鈕 → 文字變粗
- [ ] *斜體* - 選取文字 → 點擊 Italic 按鈕 → 文字變斜
- [ ] <u>底線</u> - 選取文字 → 點擊 Underline 按鈕 → 文字有底線
- [ ] ~~刪除線~~ - 選取文字 → 點擊 Strikethrough 按鈕 → 文字有刪除線
- [ ] `程式碼` - 選取文字 → 點擊 Code 按鈕 → 文字變成行內程式碼格式

### 2️⃣ 標題 (2 個)
- [ ] # 大標題 (H1) - 游標在行首 → 點擊 H1 → 該行變大標題
- [ ] ## 中標題 (H2) - 游標在行首 → 點擊 H2 → 該行變中標題

### 3️⃣ 列表 (3 個)
- [ ] • 項目符號 - 點擊按鈕 → 出現圓點列表
- [ ] 1. 編號列表 - 點擊按鈕 → 出現數字列表
- [ ] ☑ 待辦清單 - 點擊按鈕 → 出現可勾選的待辦項目

### 4️⃣ 特殊元素 (2 個)
- [ ] > 引用區塊 - 點擊按鈕 → 該行變引用格式
- [ ] --- 分隔線 - 點擊按鈕 → 插入水平分隔線

### 5️⃣ 表格 (6 個)
- [ ] 📊 插入表格 - 點擊按鈕 → 插入 3x3 表格(含表頭)
- [ ] 🗑️ 刪除表格 - 在表格內點擊 → 整個表格被刪除
- [ ] ➕ 新增行 - 在表格內點擊 → 下方新增一行
- [ ] ➖ 刪除行 - 在表格內點擊 → 當前行被刪除
- [ ] ➕ 新增列 - 在表格內點擊 → 右方新增一列
- [ ] ➖ 刪除列 - 在表格內點擊 → 當前列被刪除

## 測試步驟
1. 打開工作筆記頁面
2. 創建新筆記或編輯現有筆記
3. 逐一測試每個功能
4. 記錄哪些功能正常 ✅ 哪些功能失敗 ❌

## 已知問題
- [ ] 若功能失敗,記錄錯誤訊息
- [ ] 檢查瀏覽器 Console 是否有錯誤

## 測試結果
請在每個項目前標記:
- ✅ 功能正常
- ❌ 功能失敗
- ⚠️ 部分正常但有問題
